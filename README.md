## 🎯 نبذة عن المشروع

**هواتف ماركت** هو متجر الكتروني متخصص في بيع الهواتف الذكية والإكسسوارات في الجزائر. يوفر تجربة تسوق احترافية مع واجهة حديثة وآمنة.

### ✨ المميزات الرئيسية

- 📱 **واجهة احترافية**: تصميم حديث وسهل الاستخدام
- 🔍 **بحث وتصفية متقدمة**: ابحث حسب الماركة، الفئة، والسعر
- ⚖️ **مقارنة المنتجات**: قارن بين هاتفين جنباً إلى جنب
- 💳 **نظام طلبات آمن**: معالجة آمنة للطلبات
- 📦 **تتبع الطلبات**: تابع طلبك في الوقت الفعلي
- ⭐ **نظام التقييمات**: قيّم المنتجات وشارك آراءك
- 🌙 **وضع ليلي/نهاري**: اختر النمط المفضل لك
- 📲 **تطبيق PWA**: ثبّته على هاتفك كتطبيق
- 🔐 **أمان عالي**: تشفير وحماية البيانات

## 🚀 البدء السريع

### المتطلبات

- متصفح ويب حديث (Chrome, Firefox, Safari, Edge)
- اتصال إنترنت
- Firebase Account (مجاني)

### التثبيت

1. **استنساخ المستودع**:
1. **استنسخ المستودع**:
   ```bash
   git clone https://github.com/rahimltr64-lgtm/R.shop.git
   cd R.shop
   ```

2. **نسخ ملف متغيرات البيئة**:
2. **انسخ ملف متغيرات البيئة**:
   ```bash
   cp .env.example .env
   ```

3. **ملء بيانات البيئة**:
   ```bash
   # عدّل .env بـ بياناتك
3. **ملأ بيانات البيئة**:
   ```bash
   # عدّل .env بـ بيانات
   FIREBASE_BASE_URL=your_firebase_url
   TELEGRAM_TOKEN=your_token
   TELEGRAM_CHAT_ID=your_chat_id
   ADMIN_PASSWORD=your_password
   ```

4. **فتح الموقع**:
   ```bash
   # استخدم أي خادم محلي
   python -m http.server 8000
   # أو
   npx http-server
   ```

5. **زيارة الموقع**:
   - المتجر: `http://localhost:8000`
   - لوحة التحكم: `http://localhost:8000/dashboard.html`
