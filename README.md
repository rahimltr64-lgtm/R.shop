## 🚀 البدء السريع

### المتطلبات
- متصفح حديث (Chrome, Firefox, Safari, Edge)
- اتصال إنترنت
- حساب Firebase (اختياري للتطوير)

### التثبيت والتشغيل

1. **استنسخ المستودع**
```bash
git clone https://github.com/rahimltr64-lgtm/R.shop.git
cd R.shop
```

2. **شغّل السيرفر المحلي** (اختياري)
```bash
python -m http.server 8000
# أو باستخدام Node.js
node -e "require('http').createServer((q,s)=>require('fs').createReadStream(require('path').join('.',decodeURI(q.url.split('?')[0]))).pipe(s)).listen(8000)"
```

3. **افتح المتجر**
```
http://localhost:8000
```

### الوصول لوحة التحكم
- الرابط: `/dashboard.html`
- البريد: admin@phones-market.com (Firebase Auth)
- كلمة المرور: من إعدادات Firebase
